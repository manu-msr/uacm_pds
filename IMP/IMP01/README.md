# IMP01 — Analizador léxico

**Estado:** pendiente.

Esta versión se incorporará cuando las notas completen el lexer funcional del
IMP básico. Recibirá texto fuente y producirá tokens con tipo, lexema, línea y
columna.

La versión deberá incluir la especificación léxica, el controlador en Python,
ejemplos, pruebas y las dependencias necesarias para ejecutarla.
